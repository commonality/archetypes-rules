archetypes

The archetypes namespace is an abstract container used to hold a logical grouping of unique identifiers or symbols; this case, the rules namespace. Namespaces organize code elements (such as functions, variables, and classes) into distinct scopes to prevent naming conflicts between different libraries or modules that might otherwise share the same identifier names.
