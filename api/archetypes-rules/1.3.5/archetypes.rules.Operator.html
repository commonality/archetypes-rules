Class: Operator

archetypes.rules.Operator(name, optionsopt)

(Boolean) Operators represent specific words, symbols, or logical connectors used to combine, narrow, or broaden search parameters in databases, search engines, and programming. They function by establishing relationships between keywords or conditions to produce a precise set of results or a true/false value.
