Class: Proposition

archetypes.rules.Proposition(name, value)

A (boolean) Proposition is a declarative statement or sentence that has a distinct truth value of either true or false, but not both.

Example

The classic categorical syllogism

import { Proposition } from 'archetypes-rules'

const humanMortality   = new Proposition( 'allHumansAreMortal', true )
const socratesIsHuman  = new Proposition( 'socratesIsHuman', true ) const
socratesIsMortal = humanMortality.and(socratesIsHuman)
