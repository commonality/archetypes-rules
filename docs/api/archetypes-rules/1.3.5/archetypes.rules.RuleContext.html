Class: RuleContext

archetypes.rules.RuleContext(name)

Contains the informational context for the execution of a Rule. RuleContexts represent this information as a Map of RuleElements, namely, Propositions and Variables.

⚠️ Note: RuleContexts do not contain Operators.
